# Tailor CV

Use the portable implementation at `../../.agents/skills/tailor-cv/SKILL.md` as the complete operating contract. Read it before acting and resolve its relative resources from `../../.agents/skills/tailor-cv/`.

For a CV-only request, run its native `journey` route. Pause for candidate-confirmed role, location, work-mode, authorization, sponsorship, relocation, availability, and deal-breaker answers before public search. Discovery and proposals are read-only. Never apply a proposal without a separate explicit approval naming its digest, change IDs, and variants.
